This plugin is a fork of a public Dalamud plugin that appears to be in **abandoned**. I am doing my best to keep it updated with the recent changes, including API15 and Simplepush 1.0 changes.

## PushyFinder for FINAL FANTASY XIV
A Dalamud plugin to ping your phone via Pushover, ntfy, or SimplePush whenever a Party Finder event or duty pop happens with an AFK client.

## Usage
Install the plugin, configure it using `/pushyfinder`, go AFK (look for the red icon) and enjoy.

You will need a valid  license to use Pushover OR Simplepush.
